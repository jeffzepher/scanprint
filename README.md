# 纸间 · 随身扫描

手机优先的本地扫描 PWA，第三方处理库随站点打包，不上传照片，不调用 AI 服务。

运行：`npm start`，电脑打开 http://localhost:5173 。同一 Wi-Fi 下手机可访问电脑局域网 IP 的 5173 端口进行功能预览；HTTP 局域网地址无法启用 Service Worker 或可靠安装。手机完整安装和离线使用需要部署到 HTTPS 静态站点。

支持：批量导入照片、四角拖动和透视拉正、白纸范围估计、旋转、原图/自然/文字/黑白增强、亮度、彩色笔迹清理、页面排序、当前文档本地保存、多页 JPEG 图片型 PDF 导出、桌面安装与离线缓存。

自动裁剪使用明亮低饱和纸张的启发式检测，对白底白纸、复杂背景或阴影可能不准确，必须检查四角。彩色笔迹清理会同时移除彩色正文，无法恢复被遮挡文字；不支持可靠去除黑色手写。PDF 暂无 OCR 文字层。

导入图片最长边压缩到 2400 像素；预览使用缩略图，导出使用保存的大图。当前只保存一份工作文档，新建会清空当前文档。浏览器清理站点数据、隐私模式或设备存储不足可能导致数据丢失，请导出重要文档。首次完整加载后可离线打开；没有远程字体或外部脚本请求。

部署静态文件：index.html、style.css、app.js、sw.js、manifest.webmanifest、icon.svg、icon-192.png、icon-512.png。更新资源时同步修改 sw.js 的缓存版本。


## 图像处理升级（v3）

OpenCV.js + jscanify 随站点本地打包，无外部 CDN 请求。首次完整加载后离线可用。自动裁剪使用多组边缘检测、闭运算和四边形轮廓评分，识别结果仍需确认。文字增强使用纸面背景估计、光照归一化和局部增强；黑白使用局部阈值。自然增强保留彩色。支持去阴影强度调节、后台线程处理；重复编辑保留增强前底图和参数。

可减轻浅折痕明暗，不能铺平弯曲文字、修复失焦或恢复被遮挡内容。DocRes / UVDoc 模型尚未接入。

部署必须额外包含 processing-core.js、scan-worker.js 和整个 vendor 文件夹。OpenCV.js 约 11 MB，首次缓存需要下载完整引擎。无需编译。

检查：node verify.cjs；node verify-processing.cjs。后者实际加载 OpenCV WASM，验证倾斜纸张检测、纯色背景拒识、渐变阴影归一化和笔画保留。合成测试不能替代 iPhone 实拍验证。


## v5：两步编辑与手动曲面校正

编辑先进行纸张边界裁剪，点击下一步再增强或铺平；可以返回裁剪。预览限制为视口高度约 40%、最高 320px，四角坐标与图片保持相同比例。导出仍使用保存的大图。

边界检测增加低饱和纸张区域分割，支持部分边缘出框；白色桌面、彩色纸张和低对比场景仍可能失败，必须确认候选边界。

第二步提供手动上下弯曲参数，通过几何重采样校正简单弯曲。请先把文字旋转到横向。此功能不是自动 AI 去畸变；复杂褶皱、书脊压缩和缺失内容不能可靠恢复。无上传、无外部服务。参数与底图分别保存。


## v6：裁剪触摸与边缘清理

图片四周增加 30px 操作留白，角点触摸直径约 46 CSS px，图片坐标仍按原图片区域计算。纸张候选边界进一步搜索彩色背景到低饱和纸面的过渡。

处理步骤新增边缘留白：默认覆盖短边尺寸 1.2% 的外缘，可调 0–3%；不会自动识别正文，靠边内容也会被覆盖，务必预览并按需调小。原图模式不应用边缘清理。

去阴影补偿纸面光照差，文字模式本身有局部背景清理，滑块变化可能较自然模式不明显。亮度在原图/自然模式调整明暗，在文字/黑白模式显式调整笔画深浅。手动铺平只对简单曲面做几何重采样，请先旋转至文字横向并启用；不是全自动去褶皱。


## v7：文件签字与工具箱

首页新增文件签字入口，支持图片和未加密 PDF。可以输入文字（使用设备字体）或触屏手写，选择黑色/蓝色，撤销笔画；添加后拖动定位、调节大小、删除。PDF 支持逐页添加多个签名，导出保留原页面和文字，在原文件上叠加签名图片。图片可导出 PDF 或 PNG，最长边限制 2400px。

签字文件及签名只保留在当前页面内存中，刷新/关闭页面后清除；签字并非证书数字签名。全部处理在本机完成。首次缓存资源后支持离线。部署额外包含 signature.js、signing-core.js 及 vendor 中的 PDF.js/PDF-lib 文件；无需编译。发布可直接解压 scanprint-update.zip 到 GitHub Pages 的发布目录。

验证：node verify-signing.cjs，覆盖 0/90/180/270 度旋转页面的签名坐标、多页 PDF 和原文字保留、签名边界限制。仍需在真实 iPhone 上检查手写与下载体验。


## v8：最近文件与手机操作

首页以缩略图、页数、名称、时间、大小展示扫描和签字历史，可按类型筛选，点击继续编辑，通过更多菜单删除或下载已导出的文件。本地历史保存在 IndexedDB（zhijian-history），不会上传；浏览器清理站点数据会删除历史。旧扫描工作区会自动加入历史。每次点击“照片扫描”开始另一份文档，原文档保留在历史；“文件签字”打开全屏空白文件页，旧签字从历史单独打开。

签名支持调整大小、手写笔粗（可改变已有笔画）、左右 90° 旋转与任意角度旋转；方向会烘焙到透明签名图片，PDF 与 PNG 导出使用相同结果。图像增强移除手动铺平、亮度和去阴影滑块，使用固定自动增强参数，保留边缘留白。

首页顶部向下拖动并松手更新页面及离线资源；编辑弹层、画布和按钮上的触摸不触发刷新。离线时更新失败提示后保留本地内容。部署新增 history.js，缓存版本 v8。


## v9：更新可见性与手写笔粗

修复首页导航长期命中旧缓存的问题：导航优先读取联网最新页，失败时回退本地缓存。工具箱下直接展示扫描与签字历史、类型数量及空列表提示。页首提供“更新 v9”按钮；新资源接管后出现更新提示。首次从旧版升级可访问 ?v=9 避免旧首页缓存，历史 IndexedDB 不受影响。

手写笔粗按屏幕 CSS 像素换算到画布，范围 0.5–14px；调整时已有笔画同步变化。验证缓存更新策略：node verify-updates.cjs。


## v10：已导出签字文件历史

每次导出签字 PDF/PNG，独立保存该次文件的 Blob、缩略图、时间与编辑源数据。以后编辑或再次导出不会覆盖旧文件。签字历史仅列出已导出文件；点击预览，菜单支持继续编辑、下载、删除。删除后草稿保存不会重新生成该导出记录。旧版已保存的导出文件仍可查看。所有历史只在当前浏览器本地存储。iPhone 内嵌 PDF 预览不完整时可点击“在浏览器中打开完整文件”。验证：node verify-sign-history.cjs。


## v11：证件扫描与人像证件照

证件扫描：支持手机拍照、相册导入正反面，自动候选边界与手动四角裁剪、旋转、透视拉正；身份证/银行卡按 85.6 × 54mm 放在 A4，可上下/左右拼版，也可单面；其他证件保留比例。可自然增强，导出 PDF 后独立保存本地历史，可预览、下载、删除、继续编辑。自动检测依赖现有边缘引擎，低对比或彩色证件可能需要手动裁剪。

人像证件照：支持前置拍照或导入，提供一寸 25×35mm、二寸 35×49mm、小二寸 33×48mm，缩放与位置微调，原背景或本地人像分割后切换白/蓝/红底。导出 300 DPI 像素尺寸且写入 pHYs 元数据的 PNG、实际尺寸单张 PDF、152×102mm 相纸排版 PDF，保存本地导出历史。模型是通用人像分割，发丝/背景相近衣物仍需检查；不作证件合规自动判定。

MediaPipe SIMD/非 SIMD WASM 与自拍分割模型放在 vendor/vision（约 20MB），首次智能抠图才下载并运行，不纳入启动预缓存；用过后缓存对应组件，以供离线使用。无需外部 AI 服务。部署须包含 documents.js、document-core.js 及整个 vendor/vision，静态服务器需提供 .mjs 的 JavaScript MIME 和 .wasm 的 application/wasm。GitHub Pages 支持这些文件。

验证：node verify-documents.cjs（毫米布局、裁剪边界、证件比例、相纸不重叠、导出 PDF 页尺寸与 WASM 校验）。尚需真实 iPhone 验证拍照、模型执行、抠图边缘和 PDF 预览体验。


## v12：人像拍摄构图与更多尺寸

“拍摄人像”改为网页实时相机，覆盖头部、耳朵、颈肩轮廓、中线、眼线和照片边角；可切换前后相机，在拍摄页选择尺寸，快门只保存视频中实际照片区域，不写入参考线。自拍预览镜像，保存正常方向。关闭、取消、切换相机或离开页面后停止摄像头；权限拒绝或不支持时保留系统相机与相册入口。网页相机需要 HTTPS 或 localhost。

新增小一寸 22×32、大二寸 35×53、三寸 55×84、35×45、40×60、50×50 和 51×51，连同原有规格共 10 个预设。支持自定义宽 10–100mm、高 10–150mm，构图、单张导出及历史编辑均保留自定义尺寸。过大尺寸不能放入 6 寸相纸时提示使用单张导出。尺寸只表示输出规格，不自动判定办理机构要求。

验证：node verify-camera.cjs（模拟相机权限与生命周期，拍摄/预览裁剪一致性，扩展尺寸和输入边界）；node verify-documents.cjs。未替代 iPhone 摄像头实机测试。


## v13：人像参考线与换底
扩大头部轮廓并缩短至双肩，提高拍摄区域可用宽度。换底色自动运行本地分割，显式 HTML canvas 避开 Safari OffscreenCanvas 路径，显示模型加载阶段并检查下载和分割有效性，失败可重试。改善透明蒙版背景残留。尚需 iPhone 实机验证模型执行与发丝效果。


## v14：相机视野
实时相机默认完整显示画面，避免 cover 为填满窄照片而放大头像。支持 70%–200% 画面大小调节，拍摄和预览保持相同缩放与居中位置；缩小留白为白色，可换底统一。自拍仅预览镜像，保存正常方向。相机请求避免强制纵向尺寸裁切。验证模拟相机不同缩放的预览/导出一致性，仍需手机实测视野。


## v15：证件照细节
拍摄保存传感器对应构图分辨率（最长边上限2400），避免在拍摄时提前压成300DPI小尺寸。编辑预览按600DPI像素渲染，导出保持选定实际尺寸300DPI。抠图采用较宽软边过渡、1200像素蒙版插值和图像引导滤波，原图颜色细节独立保留。算法测试覆盖蒙版边界、透明度范围和相机保存分辨率；未替代真机发丝视觉评估。


## v16：扫描比例与细字
扫描四角拉正改为根据透视方向估算矩形比例，避免用最大边长直接输出而把倾斜纸张压成近似正方形；相机中心/焦距未知时为近似估算，折页和非矩形纸仍可能有误差。证件扫描保留原有逻辑。文字增强降低加黑倍率、保留灰度边缘，预览基于完整分辨率处理。用用户原图局部验证比例恢复，并通过合成倾斜纸张与细字测试；原图虚焦不具备真实细节恢复能力。


## v17：浅色细字
文字模式增加有界细节锐化和局部方差控制的对比度，增强浅色小字且不扩张笔画。文字/黑白结果存为PNG，标准PDF采用更高JPEG质量。用户样张对照检查显示浅字稍有改善，原图虚焦和像素不足仍无法可靠恢复；未作OCR重绘。测试覆盖浅字相对v16对比度、平坦背景、正常笔画保留。


## v18：界面配色
暖白底色与青绿主题，工具入口使用青绿、淡紫、琥珀、浅蓝图标底色；历史卡片、分段筛选、编辑控件和导出栏统一视觉层次。保持手机窄屏布局和相机深色画面，尊重减少动态效果偏好。


## v19：扫描省墨
增强模式按钮下方新增省墨复选框，文字增强/黑白有效。降低笔迹浓度并保持白纸背景，实时预览和导出一致；历史编辑恢复选择，重置关闭。实际耗墨量依打印机设置而异。


## v20：多图批量扫描
选择多张照片后逐张执行纸张边界识别、透视裁剪与文字增强，显示阶段/数量进度。逐张保存，保持输入顺序，支持当前图片结束后停止后续导入。边界失败保留完整画面并标记待检查，增强失败保留原图；单个读图失败不中断其他照片。原图始终保留，可单独编辑或重置。单张导入保持手动两步编辑。验证覆盖正常/失败路径、顺序、停止后续及单张编辑回归。


## v21：贴边书页裁剪
增加贴近画面边缘的长页边/书脊线检测，在主要页面占大部分视野时排除狭窄相邻页。完整纸张继续使用轮廓检测；缺角照片不按真实纸张四角强行恢复比例。通过两张用户实图及合成贴边书页、普通纸张与空白图回归验证。只识别照片内可见部分，不恢复镜头外内容，也未增加曲面铺平能力。


## v22：文字与实黑区域保留
修正局部均值增强会将实黑内部洗白的问题：纸张光照归一化后，同时结合绝对墨色和局部笔画对比度；扩大背景估计范围，软过渡抑制弱透印。文字模式保留灰度边缘，省墨仍为可选项。使用两张书页原图作处理对照，并验证实黑/灰色内部、浅字、弱透印、白纸、黑白与原图模式。属于图像增强，不作OCR重排；仍可能残留强透印或无法恢复虚焦细节。
